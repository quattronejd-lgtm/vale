# Savvy Lab Solutions — Brand

Brand assets and guidelines for Savvy Lab Solutions, stewarded by Quattrone Brands.

- **[`brand-book.html`](./brand-book.html)** — interactive brand book, v1.1. Self-contained (fonts embedded, no network needed); open in any browser. Includes an **Onyx / Cream theme toggle** previewing the brand on dark and light grounds — the same two modes the website will ship in.
- **[`brand-book.md`](./brand-book.md)** — the written guidelines, v1.1.
- `assets/` — (pending) master logo files: Shaana's original PNG, production vector (SVG/EPS), and licensed OC Bartok font files. Until they land, the lockup in the HTML book is a live vector recreation using Cormorant / Montserrat stand-ins.
