# The AI Operator — Cohort 02 · Soft-Launch Kickoff

A 15-slide presentation for the Cohort 02 kickoff (July 21, 2026), built in the
Quattrone Brands 2026 standard (Ink Navy ground, Signal Teal accent, gradient
as signal) and blended with the "Same Loop, Better Tooling" site narrative.

## Presenting

Open `index.html` in any browser. Fully self-contained — fonts embedded, works offline.

- **Navigate:** arrow keys, space, or click the on-screen controls. Number keys jump to a slide. `R` resets.
- **Speaker notes:** embedded per slide in the `#speaker-notes` JSON block.
- **PDF export:** File → Print → Save as PDF gives one clean 1920×1080 page per slide.
